How AI Mike evaluates

A transparent baseline evaluation workflow.

  • 1Text normalization
    Ignores capitalization, common punctuation, and repeated spaces.
  • 2Word-overlap score
    Measures overlap between response and reference words. It does not understand meaning.
  • 3Exact match flag
    Identifies whether normalized response text exactly matches the reference.
  • 4Human review
    A reviewer decides whether a difference is actually an error.
